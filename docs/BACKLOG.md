# Product Backlog

Copia cada fila como una tarjeta en tu tablero Kanban (Pendiente / En proceso / Completado), con el código como prefijo del título.

| Código | Historia de usuario | Criterios de aceptación | Prioridad |
|---|---|---|---|
| APP-01 | Como usuario, quiero registrarme e iniciar sesión para acceder a la app. | Registro con nombre, rol, correo y contraseña; login; cierre de sesión; errores claros. | Alta |
| APP-02 | Como usuario, quiero ver y editar mi perfil para que otros me identifiquen. | Se muestra el rol; se editan nombre y descripción; el rol no es editable. | Media |
| APP-03 | Como tutor, quiero publicar una tutoría para ofrecer mi ayuda. | Título, materia, fecha/hora, cupos; solo visible el formulario para tutores. | Alta |
| APP-04 | Como estudiante, quiero listar y buscar tutorías para encontrar la que necesito. | Solo tutorías futuras; búsqueda por materia, título o tutor; muestra cupos libres. | Alta |
| APP-05 | Como estudiante, quiero reservar un cupo para asegurar mi asistencia. | No permite reservar sin cupo ni la propia tutoría; no duplica reservas. | Alta |
| APP-06 | Como estudiante, quiero ver y cancelar mis reservas para gestionar mi agenda. | Lista con estado; cancelar libera el cupo. | Media |
| APP-07 | Como estudiante, quiero calificar una tutoría para dar retroalimentación. | Solo tras la fecha; 1–5 estrellas y comentario; una sola calificación. | Baja |
| APP-08 | Como tutor, quiero ver inscritos y calificaciones para preparar mis sesiones. | Lista de inscritos por tutoría, cupos usados y promedio. | Media |
